# 🌡️ IoT Temperature Monitoring & Automatic Cooling System

## 📌 Overview
This project monitors temperature in real-time using IoT and automatically controls a cooling system based on threshold values.

It also allows manual control through a mobile application.

## ⚙️ Components Used
- ESP8266 (NodeMCU)
- DHT11 Temperature Sensor
- L298N Motor Driver
- Cooling Fan / Motor
- Blynk IoT Platform

## 🔌 Working Principle
- The DHT11 sensor reads temperature data
- ESP8266 sends data to Blynk app via WiFi
- If temperature exceeds threshold:
  - Cooling system turns ON automatically
- User can also control the system manually using the app

## 📱 Features
- Real-time temperature monitoring
- Automatic cooling system
- Manual override using Blynk
- Wireless control via IoT

## 📷 Output
Displays temperature on mobile app and controls cooling system accordingly.

## 💡 Applications
- Smart homes
- Industrial monitoring
- Server room cooling systems
